# Hardware

The hardware pages, one per board, now live in the
[redox-rpi wiki](https://github.com/redox-rpi/redox-rpi/wiki):

- [Pi 3B+](https://github.com/redox-rpi/redox-rpi/wiki/Pi-3B-plus): BCM2837B0, block diagram, address maps, boot, clocks, power chip, peripherals, GPIO, USB
- [Pi 400](https://github.com/redox-rpi/redox-rpi/wiki/Pi-400): BCM2711, address maps, EEPROM boot, GIC, PCIe and VL805, GENET
- [Pi 5 and CM5](https://github.com/redox-rpi/redox-rpi/wiki/Pi-5): BCM2712 + RP1, boot, PSCI, debug UART, from public documents
